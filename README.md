# BLACKGLASS — DFIR Trainer

An interactive learning emporium for digital forensics and incident response. BLACKGLASS combines curated learning galleries, short interactive field-guide slides, knowledge checks, a viewing room of external training resources, and a fictional Trojan-response case simulator.

## Learning galleries
- Malware & execution
- Digital evidence
- Network forensics
- Persistence & lateral movement
- Incident response
- Threat hunting

## Experience
- Responsive navigation and gallery layout
- Interactive field-guide slides and a knowledge check
- Curated links to CISA, NIST and Cyber Triage learning resources
- A separate case simulation for evidence collection and response decisions

## Run locally
Open `index.html` in a modern browser. No build step or package installation is required.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. The site should publish at `https://hak3du.github.io/blackglass-trojan-lab/`.

## Safety and scope
The learning content is defensive and educational. Scenario telemetry is fictional. The case simulator does not execute malware, spawn processes, alter registry settings, modify host files or make network connections. External video and training resources remain hosted by their original publishers.

## Project status
A polished front-end training experience and first case exhibit. It is not a production LMS: there is no user authentication, server-side progress tracking, assessment backend, content-management system or formal certification workflow yet.
